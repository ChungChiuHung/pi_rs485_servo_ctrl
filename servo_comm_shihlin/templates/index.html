Set home position

Move the motor to the mechanical home position first, then press SET HOME NOW: the current shaft position becomes 0° and is saved as home. Recorded Set Points are measured from home, so they refer to the new zero afterwards. Nothing moves.

No RS-485 serial port connection. Motor control is unavailable; nothing is being sent to the drive.

Speed Control (JOG)

↑ ← ↓ →
No click-to-spin buttons here on purpose: rotation only runs while a key is physically held down, so it can never be left spinning by a stray click. While enabled -- Left/Right arrow keys = rotate CW/CCW (release the key = stop immediately); Up/Down arrow keys = speed +/-1 rpm. Keys only act while this page has focus and the cursor isn't in a text/number field.
